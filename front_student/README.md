# CIA Project — Frontend

React + TypeScript + Redux frontend for the CIA inventory management system.

## Tech Stack
- React 16
- TypeScript
- Redux + Redux Thunk
- Axios
- Bootstrap

## Setup
```bash
yarn install
yarn start
```

## Environment
Set `REACT_APP_API_URL` in `.env` to point to the API server.

## Features
- JWT Authentication
- Products management (CRUD)
- Orders management (CRUD)
- Dashboard with real-time stats
- User management
