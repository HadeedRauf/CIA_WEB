# CIA Project — Backend API

Node.js + TypeScript + TypeORM + Express API for the CIA inventory management system.

## Tech Stack
- Node.js 11
- TypeScript
- TypeORM
- Express
- MySQL
- JWT Authentication
- Swagger UI

## Setup
```bash
yarn install
yarn start
```

## API Endpoints
- POST /auth/login — authenticate
- GET /product — list products
- POST /product — create product (ADMIN)
- GET /order — list orders (ADMIN)
- POST /order — create order (ADMIN)
- GET /user — list users (ADMIN)
